# Todos project
This project is simple application for user to organize daily task build with **React** and **Vite**

---
## Installation instruction

**Clone the repository from github**

---

## Navigate into project folder

```bash
cd todos
```
---
## Install project dependencies

```bash
npm install

```
---
## Run development server
```bash
 npm run dev
```
 After running the command, you will get a local URL (for example: http://localhost:5173), copy the URLS and open on browser to see the app
